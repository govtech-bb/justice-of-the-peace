About these pins: the official Supreme Court register lists each JP's parish and address as text only — it does not include map coordinates. The pin positions on this map are approximate: each JP is placed inside their parish but not at their exact street address. The list shows each JP's home address by default; if only a work address is on the register, the row is tagged "Work address".
